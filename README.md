Казино-рулетка для пользователей сайта GOROD24.BY с системой баланса.

== Описание ==

Плагин добавляет на сайт игру в европейскую рулетку:
- Пользователи играют на свой внутренний баланс (BYN)
- Администратор пополняет балансы пользователей вручную
- Полная история игр и транзакций
- Красивый тёмный интерфейс с анимацией колеса

== Установка ==

1. Загрузите папку `gorod24-casino` в директорию `/wp-content/plugins/`
   (ИЛИ установите через Плагины → Добавить новый → Загрузить плагин → выберите zip-файл)
2. Активируйте плагин в разделе «Плагины» в панели WordPress
3. Используйте шорткод [gorod24_roulette] на любой странице или записи

== Использование ==

=== Для администратора ===
1. Перейдите в «Casino Рулетка» в меню WordPress
2. Пользователь оплачивает на вашу карту нужную сумму
3. Выберите пользователя из списка, введите сумму → «Пополнить»
4. Деньги появятся на балансе пользователя сразу

=== Для пользователей ===
1. Войдите на сайт
2. Перейдите на страницу с шорткодом [gorod24_roulette]
3. Выберите ставку и сумму
4. Нажмите «КРУТИТЬ»
